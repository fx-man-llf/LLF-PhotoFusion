LLF PhotoFusion 1.2 － スキャン画像の自動結合
==============================================

無料ソフトウェアです。どなたでもご利用いただけます。
(c) 2026 LLF  -  https://www.laludotheque.fr  -  https://www.lalogitheque.fr

LLF PhotoFusion は、Photoshop の「Photomerge」と同じことをスキャン画像で
行います。各画像の位置と向きを自動で見つけ、用紙やスキャナーによる小さな
ゆがみを補正し、継ぎ目の見えない1枚の画像に合成します。出力は元画像と同じ
形式・同じ解像度（dpi）です。
対応形式：JPG、PNG、TIFF（8/16ビット）、BMP、WEBP、JPEG 2000、カメラRAW

インストールと起動
  Windows 11 ：「Lancer LLF PhotoFusion (Windows).bat」をダブルクリック。
                初回起動時に Python と必要なモジュールが自動でインストール
                されます（インターネット接続が必要、数分かかります）。
                「Creer un raccourci sur le Bureau (Windows).bat」を実行すると
                デスクトップにアイコンが作成されます。
  Linux Mint ：最初に一度だけ端末で  sudo apt install python3-venv
                その後 ./lancer_photofusion_linux.sh を実行します。
使用中は小さなコンソール画面を閉じないでください。
処理はすべてお使いのパソコン上で行われ、画像がインターネットに送信される
ことはありません。

使い方
  言語：画面右上のメニュー（🌐）で日本語・英語・フランス語を選べます。
  1. 画像を追加します（ボタンまたはドラッグ＆ドロップ）。最初の画像が
     「基準画像」となり、結果の向きを決めます。
  2. 「自動で結合」をクリック。赤いままの画像があれば、「配置」タブで
     だいたいの位置までドラッグし、必要なら回転して、もう一度実行します。
  3. 設定：傾き補正、余白の切り取り、出力形式。
  4. 「最終画像を作成」：指定したフォルダーに保存されます。ビット深度、
     dpi、カラープロファイルは元画像と同じです。
